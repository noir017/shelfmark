# shelfmark 单页工作区设计稿

状态：已实现
范围：网页 `web/`，连带插件新标签页的 `startPage` 兼容
不改：服务端数据模型、WebDAV/Floccus、导入导出格式

## 1. 现状

网页现在有 5 个底部 tab：起始页、管理、搜索、收藏、设置。

- 起始页和管理页看的是同一棵树，却是两套布局、两套交互。起始页点文件夹会跳到管理页，视觉和操作都断一次。
- 搜索、收藏、设置各占一个 tab，但都是低频或上下文操作，不值得常驻导航。
- 移动端 5 个 tab 占掉一整条底栏，“起始页”和“管理”语义重叠，用户不知道该点哪个。

## 2. 目标

- 一个主工作区：浏览、搜索、新建、编辑、移动、删除、多选都在同一页面完成。
- 没有底部 tab，也没有“浏览模式/管理模式”的切换。列表本身就是可编辑的。
- 设置、历史、回收站、待确认、失效链接、重复书签收进顶栏“更多”，作为二级页面或浮层。
- 保留深链接和浏览器返回：文件夹、搜索结果、分享参数都能直接打开。
- 移动端优先，桌面端增强；不引入大型 UI 库。

非目标：不改书签树和同步逻辑，不改导入导出，不做多人协作。

## 3. 信息架构

改前：

```
底部 tab：起始页 | 管理 | 搜索 | 收藏 | 设置
起始页 --点文件夹--> 管理页
```

改后：

```
主工作区（唯一常驻页面）
├─ 顶栏：返回/面包屑 · 搜索 · 新建 · 更多
├─ 侧栏（桌面）：库切换 · 文件夹树 · 工具入口
├─ 内容区：当前文件夹 / 搜索结果
├─ 选择栏（选中时）：移动 · 标签 · 删除
└─ 浮层/二级页：新建收藏、编辑、移动、标签、设置、历史、回收站、报告、待确认
```

“一个页面”指一个主工作区。设置和历史这类低频功能仍可有独立路由，但不是平级 tab，也不复制主界面的布局。

## 4. 主页面

### 4.1 桌面（≥900px）

```
┌──────────────────────────────────────────────────────────────────┐
│ shelfmark  书签 › 工作 › 项目        ⟳ [ 筛选当前文件夹 ] [+ 新建] ⋯ │
│ 📁常用 📁工具 📁阅读  示例书签  …                                  » │
├───────────────┬──────────────────────────────────────────────────┤
│ ▾ 书签        │ ▸ 📁 常用                                      6 │
│   常用        │ ▾ 📁 工具                                      3 │
│ ▸ 工具        │     📁 在线工具                                4 │
│   阅读        │     示例书签  example.com  #tag                  │
│               │   示例书签  example.com  #tag                    │
└───────────────┴──────────────────────────────────────────────────┘
```

- 顶栏第二行是书签栏：库根的直接子项横排。文件夹悬停 250ms 弹出菜单，子文件夹悬停向右级联，点书签直接打开；悬停打开的菜单指针离开 400ms 后收起，点开的要点外面或 Esc 才收。放不下的收进 »。
- 面包屑的每个分隔符可点开，列出左边那一级的子文件夹，直接跳到同级目录。
- 左侧文件夹树始终可见，支持展开、折叠、拖放、右键菜单。
- 右侧内容区是当前文件夹的子项，文件夹可就地展开（大纲视图），展开状态和侧栏树共用、按库记在本地。
- 同步状态收成顶栏一个图标（悬停看最后同步和条目数，有待确认上传时带点）；只有锁定、缓存时才出一条细状态条。

### 4.2 移动（<900px）

```
┌──────────────────────────────────┐
│ ← 书签 › 工作 › 项目   🔍 [+] ⋯  │
├──────────────────────────────────┤
│ ▸ 📁 常用                   6  ⋯ │
│ ▾ 📁 工具                   3  ⋯ │
│     示例书签  example.com      ⋯ │
│   示例书签  example.com        ⋯ │
└──────────────────────────────────┘
```

- 顶部一行：返回、面包屑（横向滚动）、搜索图标、新建、更多。搜索框点图标才展开。没有书签栏和底栏。
- 文件夹点 ▸ 就地展开，点标题进入；面包屑分隔符点开跳同级文件夹。不再有文件夹树抽屉。
- 长按进入多选：复选框和拖动手柄出现，点行切换选择；底部出现选择栏（已选 N 项、全选、移动、标签、删除、取消）。

### 4.3 列表行

单行，桌面 28px、触屏 40px，行间无分隔线。

| 元素 | 文件夹 | 书签 |
|---|---|---|
| 左侧 | 复选框、展开箭头、文件夹图标 | 复选框、favicon |
| 主信息 | 标题 | 标题，后面灰色域名、标签、失效/跳转标记（只用剩余宽度） |
| 右侧 | 子项数、更多 | 更多 |
| 交互 | 点行进入；▸ 就地展开 | 点行打开（默认新标签页） |

- 桌面：复选框和 ⋯ 悬停才出现；整行可拖；Ctrl/⌘+点击切换选择，Shift+点击连选；右键菜单；`e` 行内编辑。
- 触屏：⋯ 常显；复选框和拖动手柄只在多选时出现，从手柄拖动；另有“移动到…”对话框。
- 列表默认按树里的顺序，不额外排序；需要排序时用批量移动或后续加排序功能。

## 5. 核心流程

### 5.1 浏览

- `/` 打开上次所在的文件夹；没有记录时打开默认库的根目录。
- 点文件夹：内容区原地切换，面包屑更新，URL 变成 `/lib/{slug}/f/{id}`；浏览器返回回到上一级。
- 顶栏品牌和面包屑第一项都回库根（`/lib/{slug}`）；`/` 本身仍打开上次位置。长按/右键文件夹可“设为启动位置”。
- 桌面用书签栏、侧栏树和面包屑下拉；移动端用就地展开和面包屑下拉。
- 没有“进入管理模式”这一步，当前列表一直可编辑（离线/只读时除外）。

### 5.2 搜索

- 顶栏只有一个搜索框：
  - 输入时即时过滤当前文件夹的标题、URL、标签、备注。
  - 按 Enter 或点“搜全部”进入全局搜索，结果替换内容区，URL 变成 `/search?q=...`。
  - 结果页顶部显示“全部书签 · N 条”和“返回文件夹”；Esc 清除搜索。
- 搜索结果按库/路径分组，保留高亮、标签、失效标记；点文件夹结果进入该文件夹，点书签结果打开网址。
- 搜索结果的每一行保留更多菜单，可以直接编辑、移动、删除。
- 删除独立搜索页和底部搜索 tab；`/search?q=` 由主工作区渲染。

### 5.3 新建/收藏

- 桌面顶栏“＋ 新建”是分体按钮：书签 / 文件夹。
- 移动端右下角“＋”打开同样两个选项。
- 书签面板字段：URL、标题、位置（默认当前文件夹）、标签、备注；粘贴 URL 自动取标题；已收藏提示；AI 建议（开启时）。
- 文件夹面板字段：名称、位置（默认当前文件夹）。
- PWA 分享 `/share?url=...&title=...&text=...` 打开同一个面板，预填分享内容；保存后回到原文件夹。
- 离线时保存进队列，面板显示“已排队”。
- 删除独立收藏页和底部收藏 tab；`/add` 重定向到 `/share`。

### 5.4 编辑/整理

沿用管理页现有能力，不重写：

- 行内编辑、右键/长按菜单、多选、批量移动、批量标签、批量删除、删除撤销、拖放排序。
- 键盘：`/` 搜索、`j/k` 上下、`←/→` 折叠/展开、`Enter` 打开、`e` 编辑、`x` 选择、`Ctrl+A` 全选、`Delete` 删除、`n` 新建、`Esc` 取消。
- 同步锁、离线、只读时隐藏写操作；锁定提示在顶栏下方显示一条细状态条。
- 新建、编辑、移动、标签都用浮层，不跳页面。

### 5.5 设置与工具

- 顶栏“更多”菜单分两组：
  - 设置：账户、设备、库、导入导出、集成、用户、关于。
  - 工具：历史、最近删除、待确认上传、失效链接、重复书签、强制解锁（有锁时）。
- 设置和历史等是二级页面，顶部是“返回 + 标题”，没有底部导航。
- 待确认上传仍用顶部横幅提示；离线横幅、Access 过期横幅保留。
- 同步状态：桌面放侧栏底部；移动端只在锁定/离线/缓存时显示一条细状态。

## 6. 路由

| 路径 | 行为 |
|---|---|
| `/` | 主工作区，上次文件夹或库根 |
| `/lib/:slug` | 主工作区，库根 |
| `/lib/:slug/f/:folderId` | 主工作区，指定文件夹 |
| `/search?q=` | 主工作区，搜索结果 |
| `/share?url=&title=&text=` | 主工作区 + 收藏面板 |
| `/settings/:section` | 设置二级页 |
| `/history/:slug`、`/deleted/:slug`、`/pending/:slug/:id`、`/reports/*` | 工具二级页 |
| `/lib`、`/add` | 重定向到 `/`、`/share` |

- 主工作区不因文件夹切换重建，只切换内容区。
- 深链接、浏览器返回、PWA 分享都保持可用。

## 7. 设置与接口变更

`Settings.startPage` 删除，换成 `startLocation`：

```yaml
startLocation:
  oneOf:
    - type: string
      enum: [last, root]          # 上次位置 / 库根
    - type: object
      required: [library, folderId]
      properties:
        library: { type: string }
        folderId: { type: integer, format: int64 }
```

- `last` 是默认值：`/` 打开本设备上次所在文件夹，没有记录时打开库根。
- 旧 `startPage.sections` 非空时，取第一段迁移成固定文件夹；否则用 `last`。
- 删除 `StartPage`、`StartSection` schema 和 `StartPageSettings` 页面；`/settings/startpage` 重定向到 `/settings/account`。
- `defaultSave`、`recentSaveTargets` 保留，供分享面板和默认收藏位置使用。
- 先改 `api/openapi.yaml`，再改服务端和前端（项目约定）。

插件新标签页也读 `startPage`，需要同步改：

- 改成按 `startLocation` 显示一个文件夹（根或指定文件夹）的条目，加上搜索。
- 不再显示多段 `sections`、最近、常用；这些配置随 `startPage` 一起删除。
- 旧版插件的新标签页需要同步升级；服务端可在过渡版本继续返回一份默认 `startPage`，避免旧插件读取时报错，下个版本再删。

## 8. 组件与状态

- 删除：`pages/StartPage.svelte`、`pages/Search.svelte`、`pages/Share.svelte`、`pages/settings/StartPageSettings.svelte`。
- `pages/Manager.svelte` 收敛成 `pages/Workspace.svelte`，成为唯一主页面。
- 新增：
  - `components/ItemRow.svelte`：列表单行（含行内编辑、长按）。
  - `components/FolderMenu.svelte`：级联菜单，书签栏和面包屑下拉共用。
  - `components/BookmarkBar.svelte`：桌面书签栏。
  - `components/Breadcrumbs.svelte`：带同级文件夹下拉的面包屑。
  - `components/SearchResults.svelte`：全局搜索结果。
  - `components/SaveSheet.svelte`：新建书签/文件夹，兼容 `/share` 参数。
- 复用：`FolderTree`、`FolderPicker`、`ItemDialog`、`BulkDialog`、`BookmarkLink`、`Favicon`、`Overlays`。
- `lib/tree.ts` 的 `outlineRows` 生成大纲视图的行；`lib/longpress.ts` 是触屏长按。
- `App.svelte` 删除 `navItems`、`.topnav`、`.bottomnav`，只保留顶栏、主区、浮层。
- 新增 `lib/stores/workspace.svelte.ts`：当前库、文件夹、搜索模式、选择状态；URL 是库/文件夹/搜索的真源，`localStorage` 只存上次文件夹和视图偏好。
- 删除 `nav.start`、`nav.manager`、`nav.search`、`nav.add` 等导航文案；新增 `startLocation`、`search.scope` 等。

## 9. 迁移与兼容

- 旧链接全部可用；`/lib`、`/add`、`/settings/startpage` 重定向。
- 书签、文件夹、修订、令牌、Floccus/WebDAV 都不受影响。
- PWA `start_url` 仍是 `/`；service worker 缓存版本 +1，旧缓存刷新后进入新界面。
- 首次打开新版本：有上次文件夹记录就直接用，没有就进库根。
- 插件和网页同版本发布；过渡版本服务端继续返回默认 `startPage`，旧插件读取不会报错，下个版本再删。

## 10. 测试

单元：

- 搜索框的“过滤当前文件夹 / Enter 全局搜索”切换。
- `startLocation` 迁移：旧 sections 转固定文件夹，空 sections 转 `last`。
- 上次文件夹读写、视图偏好持久化。
- 重定向：`/lib`、`/add`、`/settings/startpage`。

端到端（Playwright，桌面 + 移动）：

1. `/` 打开库根或上次文件夹；点文件夹内容区切换、面包屑更新、返回键回退。
2. 搜索：输入过滤当前文件夹；Enter 出全局结果；点结果打开；返回文件夹。
3. 新建书签/文件夹：出现在当前文件夹；多选移动、标签、删除；删除后撤销。
4. 设置从“更多”打开；页面没有底部 tab。
5. `/share?url=...` 打开收藏面板；保存后书签出现在目标文件夹。
6. 离线：横幅、只读、排队保存。
7. 桌面侧栏树、移动端树抽屉都能跳转。

视觉回归：主工作区桌面/移动各一张基线，确认没有起始页/管理页两套布局。
